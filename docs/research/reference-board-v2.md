# Reference Board v2 — 参考サイト分解

作成日: 2026-07-07（reference-redesign-v2）

目的: Keio Ramen Guideを「慶應生の生活導線にあるラーメンを、投稿と編集で選べるWebメディア」として見せる。
主観の0→1ではなく、参考サイトの構造を分解して置き換える。

---

## 1. Billboard Live（billboard-live.com）

**盗む要素**
- 短く強いHeroコピー（1文＋サブ1文で世界観を確定させる）
- 都市別導線（TOKYO / OSAKA / YOKOHAMA が入口として並ぶ）
- Dining & Bar / Magazine のような「体験の棚」が縦に続くスクロール構成
- セクションごとに空気（背景の使い方・密度）が変わる
- 余白と強いタイポグラフィ

**盗まない要素**
- ライブハウスの高揚感・暗転背景
- 英語ポエム
- 画面を覆う巨大タイポ
- 写真前提のヒーロー演出（うちは写真ゼロ）

**Keioへの置き換え**
- TOKYO / OSAKA / YOKOHAMA → 日吉 / 三田・田町 / 横浜（Area Index）
- Dining & Bar → 今日の一杯（Featured Bowl）／投稿された一杯（Recent Logs）
- Magazine → Keio Picks・Scene Guide（特集＝店選びの文脈）
- 「セクションごとに空気が変わる」→ 罫線の太さと密度で切り替える（背景色の乱用はしない）

**反映先**: `app/page.tsx` の全体構成（Hero → Area Index → Keio Picks → Scene Guide → Recent Logs）
**優先度**: 高

## 2. Michelin Guide（guide.michelin.com/jp/ja）

**盗む要素**
- Editor's Picks（「選ばれた店」を数を絞って前に出す）
- 検索導線が常に近くにある
- 店をリストの1行ではなく「選ばれた体験」として1枠ずつ見せる
- 写真・短文・詳細導線のバランス（短い推薦文＋1アクション）

**盗まない要素**
- 高級ホテル・予約サイトの空気
- 星・点数
- ラグジュアリー写真前提の世界観

**Keioへの置き換え**
- Editor's Picks → **Keio Picks**（editorialPriority: must の店だけ。維新商店を含む3〜5店）
- ミシュラン掲載店 → 慶應生が実際に食べに行く基準の店
- 検索/予約 → 店を探す（/shops）／投稿を見る・残す（/post）
- 星の代わりに「初回注文・価格目安・一言」で選ばせる

**反映先**: `components/KeioPicks`（新設）、`app/page.tsx`、/shopsのmust店の控えめな強調
**優先度**: 高

## 3. Eater

**盗む要素**
- Heatmap / Eater 38 的な「編集された定番リスト」（網羅ではなく責任を持った数）
- 都市・エリア・用途で入る店選び
- 各店に「今行くべき理由」が1文で付く

**盗まない要素**
- ニュースメディアの更新圧・見出しの多さ
- 広告枠・レコメンドウィジェット
- 情報量過多の長文

**Keioへの置き換え**
- Heatmap → 今日の一杯（Featured Bowl。今は固定1店、将来ローテーション）
- Eater 38 → Keio Picks（must店。今は4店、育てて「Keio 12」へ）
- Area maps → Scene Guide（授業後の日吉／三田の昼／横浜で寄る…）
- 「今行くべき理由」→ 各店の selectionReason を1文で見せる

**反映先**: Keio Picks・Scene Guide・ShopCardの一言
**優先度**: 高

## 4. The Infatuation / Zagat

**盗む要素**
- 人間の言葉で選べる（データではなくひとことで決まる）
- 店ごとのキャラが伝わる短文
- 点数より「用途・雰囲気・実感」

**盗まない要素**
- 海外ノリの誇張レビュー文体
- 点数ゲーム・ランキング煽り

**Keioへの置き換え**
- レビュー本文 → 1文の判断コメント（selectionReason を主役に）
- Zagat的評価 → 価格・量・混雑・一人向け・初回注文（既存メトリクス）
- 投稿も「ひとこと」を主役にする（/postの note フィールド）

**反映先**: ShopCard（一言を先に）、Featured Bowl の一言、/postのコピー
**優先度**: 中

## 5. Beli

**盗む要素**
- 自分の行った店が残る（記録が資産になる）
- 友達の記録で次の店を選ぶ
- Want / Been 的な軽い保存（ワンタップ）
- ログが増えるほど使う理由が増えるループ

**盗まない要素**
- 大規模SNSの機能群（フォロー・通知・ランキング）
- 複雑なスコア
- ログイン必須の重さ

**Keioへの置き換え**
- 自分のラーメンログ → /postを「フォーム」ではなく「記録の入口」として見せる
- 友達の投稿 → Recent Logs／店舗詳細の投稿欄
- Want / Been → 既存の「行きたい／行った」（localStorage・ログイン不要）
- 将来の /me・/users/[handle] → account-ramen-log-v1 ブランチで準備済み（今回は出さない）

**反映先**: /postのヘッダーコピー、保存ボタンの位置づけは現状維持
**優先度**: 中

## 6. Time Out

**盗む要素**
- 都市メディアとしてのローカル導線（街から入る）
- 「その街で何をするか」という文脈で店が出てくる
- 食を生活シーンの一部として見せる

**盗まない要素**
- 観光メディアの空気（初訪問者向け説明）
- イベント情報の物量

**Keioへの置き換え**
- City Guide → Campus Guide（キャンパスの沿線＝Area Index。沿線図はHeroから降ろしてここに置く）
- Things to do → Scene Guide（授業後／空きコマ／飲み後…）
- Local picks → 慶應生の生活圏の店（全国網羅をしない宣言はAboutに）

**反映先**: Area Index（沿線図の移設・横組み化）、Scene Guide
**優先度**: 高

## 置き換え後のトップ構成

| # | セクション | 参照元 | 実装 |
|---|---|---|---|
| 1 | Hero（左コピー＋右 Featured Bowl） | Billboard Liveのコピー / Eater Heatmapの「今」 | `FeaturedBowl`新設。沿線図はHeroから外す |
| 2 | Area Index（沿線図） | Billboardの都市導線 / Time OutのCity | `AreaLineMap`を横組みバンドに再構成 |
| 3 | Keio Picks | MichelinのEditor's Picks / Eater 38 | must店3〜5（維新商店含む）を1枠ずつ |
| 4 | Scene Guide | Time OutのThings to do / Eaterの用途別 | 6シーン（授業後/三田の昼/横浜で寄る/一人/遅い時間/初めての家系） |
| 5 | Recent Logs | Beliの友達の記録 | 投稿があれば表示、なければ静かな導線 |

## 世界観（紙面・雑誌）

- 背景 #F7F4EF / 文字 #111111 / 罫線 #D8D2C8 / 赤 #C53024（最小限）
- 白カード（SaaS感）を減らす: ボックスではなく罫線で区切る。角丸・影をさらに減らす
- 太罫線（セクション頭）と細罫線（行区切り）の2段階で紙面のリズムを作る
- 写真ゼロ前提: 縦書きジャンルタイルは維持

## 実装優先度まとめ

1. 維新商店の追加（データ）と Featured Bowl（Hero）
2. トップ構成の組み替え（Area Index / Keio Picks / Scene Guide）
3. 紙面トーン（色・罫線・カードの脱ボックス化）→ /shops含む
4. /postの「記録の入口」化と店が見つからない時の導線
5. ブランドアセットの新パレット再生成（favicon/OG）
