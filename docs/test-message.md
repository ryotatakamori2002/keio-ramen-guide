## 聞きたいこと（5問・コピペ用）

1. トップを見て、3秒で「何のサイト」か伝わった？
2. 店舗カードだけで「今日行くか」判断できた？ 足りない情報は？

5. これ、友達にLINEで送れる？ 送らないなら理由は？
